売上管理アプリの使い方の説明を書いておきます。
まず、要件定義とシステム設計は作る練習はしましたが、実際できたものは少し違うものが出来ています。
このリポジトリのデータのみでは動作しません。扱えるCSVデータが必要です。

➀データが4列並び、従業員番号,担当者名,所属,在籍状況のカンマ区切りで記述され、
　従業員番号はプライマリーキーとして一意の数値が入っているCSVファイル
➁データが6列並び、売上番号,販売日,従業員番号,商品名,単価,数量のカンマ区切りで記述され、
　売上番号がプライマリーキーとして一意の数値が入っており、単価と数量はintegerに変換できる数値であるCSVファイル

を条件に、アプリが作られております。
サンプルデータとして、SalesSampleData_byOrichCSVのリポジトリにCSVファイルを置いているので、DLしてお使いください。

ディレクトリ構造は
src
├─ p9979w─CSV_SalesCalculatorApp_byKDリポジトリのデータ
└─ p9979wData─SalesSampleData_byOrichCSVリポジトリのデータ

で保存すれば使えます。もちろん、パッケージとインポート宣言などを編集すれば使えます。
